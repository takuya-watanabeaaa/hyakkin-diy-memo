# 100均DIYメモ 記事自動生成・追加ワークフロー

このワークフローは、ユーザーからの簡単な指示（例：「セリアのすのこで作る棚の記事を追加して」「このURLの記事を参考にして」）をもとに、AIが自律的にリサーチ・要約・コード追加を行うための手順です。

1. **リサーチと法的配慮の確認**
   - ユーザーから「テーマ」のみが与えられた場合、まずは `search_web` ツールを使って該当する100均DIYの作り方や参考になりそうなYouTube動画などを検索して探す。
   - ユーザーから「URL」が与えられた場合、`read_url_content` を使って内容を読み込む。
   - 他人が書いた文章をそのまま使わず、AI自身の言葉で「必要な材料」と「作りの手順」に整理・リライトする。

2. **画像の調達**
   - 法的配慮のもと、可能な限り関連する具体的なYouTube動画を検索し、そのYouTube IDを取得する。
   - YouTube動画が見つからない場合は、Unsplash等からイメージに合うフリー画像（`https://images.unsplash.com/photo-...`）を取得してサムネイルに設定する。

3. **データの生成とサイトへの流し込み**
   - `src/data/articles.ts` ファイルを `view_file` または `replace_file_content` で読み込む。
   - `articles` 配列の先頭（または末尾）に、ステップ1・2で収集した新しい記事データを挿入する。
     - IDはURLセーフな英語名にする
     - title, desc, tag, price_original, price_diy, time_est, hero_image をセットする。
     - youtube_id があればセットする。
     - ingredients リストと steps リストを構築してセットする。
   - `replace_file_content` もしくは `multi_replace_file_content` を用いて、`src/data/articles.ts` を直接書き換える。

4. **結果の報告**
   - Next.jsの開発サーバーがホットリロードされるため、ユーザーにブラウザ（`http://localhost:3000`）を更新して変更を確認するよう促す。
   - どのようなタイトルで記事を追加したか、完了した旨を簡潔に報告する。

※ ユーザーは私がコマンドを実行するのを承認するだけで、コードを書く必要はありません。
